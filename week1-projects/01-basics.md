# Claude Code Fundamentals

## คืออะไร?
- Claude Code คือ **agentic AI** ที่สามารถ:
  - แบ่ง task เป็น steps
  - เลือกใช้ tools ด้วยตัวเอง
  - ทำงานซ้ำ ๆ (loops)
  - จดจำ state ระหว่างการทำงาน

## เปรียบเทียบ
- **Traditional API**: คุณพูด → Claude ตอบ → จบ
- **Claude Code**: คุณบอกเป้าหมาย → Claude วางแผน → ใช้ tools → จบ

## ประโยชน์สำหรับ Hardware Engineer
- State machines ใน logic design → Agent workflows
- Timing diagrams → Async execution patterns
- Sequential logic → Agentic loops

ใช้ Node.js + Claude SDK
